# 💡 PitchCraft – AI-Powered Pitch Generator

PitchCraft is an **AI-driven platform** that helps users **create, refine, and save startup pitch ideas** interactively.  
Built using **React.js**, **Supabase**, and **Google Gemini API**, this project demonstrates the power of combining modern frontend frameworks with AI and cloud databases to enhance creativity and productivity.

---

## 🚀 Features

✅ **AI Chat Assistant** – Generate and refine pitch ideas using **Gemini 2.0 Flash**.  
✅ **User Authentication** – Secure signup/login with **Supabase Auth**.  
✅ **Personalized Dashboard** – View and manage all your saved pitches.  
✅ **Real-Time Data Storage** – Every chat is stored securely in **Supabase** for each user.  
✅ **Modern UI/UX** – Beautiful gradient interface using **Tailwind CSS** and **React Icons**.  
✅ **Regenerate & Download Options** – Refine and export your final pitch with ease.  
✅ **Toastify Alerts & Loaders** – Enhanced user experience with instant feedback and smooth loading states.
